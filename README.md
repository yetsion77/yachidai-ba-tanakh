# יחידאי בתנ״ך - משחק זיהוי מילים לנייד

משחק אינטרנט מעוצב ומותאם למובייל, שבו מוצגת מילה ייחודית המופיעה רק בספר אחד ספציפי בכל התנ״ך. המטרה היא לזהות את הספר הנכון מתוך ארבע אפשרויות.

המשחק מבוסס על נתוני גיליון המילים היחידאיות של התנ״ך וכולל 244 מילים מ-26 ספרים שונים.

## תכונות עיקריות
- 📱 **עיצוב פרימיום למובייל**: ממשק מודרני מבוסס Glassmorphic, צבעי זהב וכחול עמוק, עם אנימציות עשירות ואפקטים של חלקיקים.
- 🏆 **שלושה מצבי משחק**:
  - **מסלול חיים (Classic)**: 3 פסילות, 15 שניות לשאלה, מכפיל נקודות ברצף תשובות נכונות.
  - **מרוץ נגד הזמן (Time Attack)**: מתחילים מ-60 שניות, תשובה נכונה מעניקה תוספת זמן וטעות גורעת ממנו.
  - **אימון (Practice)**: ללא הגבלת זמן או חיים, כולל הצגת הפסוק המלא לאחר מענה לצורכי למידה.
- 🔊 **מחולל סאונד מובנה**: צלילי משחק נעימים (אפקטים של נכון/לא נכון/סיום משחק) הנוצרים באופן דינמי בדפדפן (Web Audio API) ללא צורך בהורדת קבצי שמע.
- 💾 **שמירת שיאים מקומית**: שמירת שיאים עבור כל מצב משחק בנפרד (`localStorage`).
- 📢 **שיתוף תוצאות**: שיתוף התוצאה שלכם בלחיצת כפתור (דרך WhatsApp, העתקה ללוח או שיתוף מערכת).

## 🚀 הוראות העלאה ל-GitHub Pages (עבור @yetsion77)

הפרויקט נבנה ללא צורך בכלי בנייה או תלות בשרתים (Pure Static Site), כך שהוא מתאים במיוחד לפרסום חינמי ומהיר ב-GitHub Pages.

עקוב אחר הצעדים הבאים כדי להעלות את המשחק לאוויר:

1. **יצירת ריפוזיטורי ב-GitHub:**
   - היכנס לחשבון ה-GitHub שלך (`yetsion77`) וצור מאגר (Repository) חדש בשם `yachidai-ba-tanakh` (או כל שם אחר שתבחר).
   - הגדר אותו כ-**Public**.

2. **דחיפת הקבצים ל-GitHub:**
   העלה את הקבצים הבאים לתיקיית השורש (Root) של המאגר:
   - `index.html`
   - `style.css`
   - `game.js`
   - `data.js`
   
   *(אם אתה עובד מול הטרמינל, תוכל להשתמש בפקודות הבאות):*
   ```bash
   git init
   git add index.html style.css game.js data.js
   git commit -m "Initial commit of Yachidai BaTanakh game"
   git branch -M main
   git remote add origin https://github.com/yetsion77/yachidai-ba-tanakh.git
   git push -u origin main
   ```

3. **הפעלת GitHub Pages:**
   - במאגר שיצרת ב-GitHub, כנס לכרטיסיית **Settings** (הגדרות).
   - בתפריט הצדדי השמאלי, תחת הקטגוריה **Code and automation**, לחץ על **Pages**.
   - תחת **Build and deployment**:
     - בחר ב-Source: `Deploy from a branch`.
     - תחת **Branch**, בחר ב-`main` (או הבראנץ' הראשי שלך) ובחר בתיקיית השורש `/ (root)`.
     - לחץ על **Save** (שמירה).

4. **זהו! המשחק באוויר 🎉**
   תוך דקה או שתיים, הדף שלכם יתפרסם בכתובת הבאה:
   `https://yetsion77.github.io/yachidai-ba-tanakh/` (בהתאם לשם הריפוזיטורי שבחרת).
